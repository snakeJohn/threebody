# 三体 · THREE BODY

沉浸式科幻致敬页 — 刘慈欣《三体》三部曲视觉体验。

**在线访问（GitHub Pages）：** https://snakejohn.github.io/threebody/

## 内容

- **三体问题实时模拟**：三恒星 + 行星的 n 体引力积分，恒/乱纪元判定
- **水滴探测器**：CSS 3D 镜面水滴 + 粒子场交互
- **经典名言**：顶部滚动条 + 主舞台轮播 + 网格点选
- **黑暗森林法则**：三条公理与智子意象

## 本地预览

直接用浏览器打开 `index.html`，或：

```bash
npx serve .
# 或
python -m http.server 8080
```

## 技术

- 纯静态：HTML / CSS / Canvas / 原生 JS
- 字体：Orbitron · Noto Sans SC · Share Tech Mono（Google Fonts）
- 部署：GitHub Pages（`main` 根目录）

## 素材

见 [ASSETS.md](./ASSETS.md)。部分插图由文生图 API 生成；动画与水滴主体为程序化渲染。

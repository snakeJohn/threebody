# 三体 · THREE BODY

沉浸式科幻致敬页 — 刘慈欣《三体》三部曲视觉体验。

**在线访问（GitHub Pages）：** https://snakejohn.github.io/threebody/

## 内容

- **三体问题实时模拟**：Velocity Verlet 积分、质心坐标系、相机自动缩放、恒/乱纪元 HUD、**注入混沌**脉冲
- **水滴探测器**：CSS 3D 镜面水滴 + 粒子场交互
- **面壁者计划**：泰勒 / 雷迪亚兹 / 希恩斯 / 罗辑
- **二向箔**：可播放的降维打击 Canvas 动画
- **智子**：锁死科学三要点
- **经典名言**：滚动条 + 轮播 + 网格（中英双语）
- **黑暗森林法则**
- **中英切换**、**程序化氛围音**

## 本地预览

```bash
npx serve .
# 或直接用浏览器打开 index.html
```

## 技术

- 纯静态：HTML / CSS / Canvas / Web Audio / 原生 JS
- 字体：Orbitron · Noto Sans SC · Share Tech Mono（Google Fonts）
- 部署：GitHub Pages（`main` 根目录）
